Data Model: Players vs Characters

👨‍👩‍👧‍👦 Family Account
Parent email, password, subscription, visual style preference
↓ has many
👤 Players (Your Kids)
Created once, persist forever
• Display name ("Luna", "Max")
• Age (for AI content calibration)
• Avatar/color preference
↓ play as
⚔️ Characters (Per Adventure)
Created for each campaign, linked to a player
• Character name ("Shadowblade Luna")
• Class (Warrior, Wizard, Rogue, Ranger)
• Story state, items, etc.
Why this matters: Add Luna once. She can be "Shadowblade Luna the Warrior" in one campaign and "Luna the Wise Wizard" in another.

Visual Style Options

Parent sets this at family level. Affects AI image generation AND narrative tone.

🌈 🐰 ✨

Whimsical

Gentlest

Bright colors, friendly creatures, storybook illustrations. No scary moments. Think: children's picture books.

Soft shadows Round shapes Always sunny
⚔️ 🐉 🏰

Heroic

Recommended

Cool and exciting! Dynamic poses, epic landscapes, real adventure vibes. Mild tension okay, but heroes always triumph. Think: How to Train Your Dragon, Pixar.

Dynamic action Cool creatures Exciting not scary
🌋 👑 ⚡

Epic

Intense

Dramatic and cinematic. Real stakes, atmospheric tension, detailed realistic characters. Can include mildly scary moments. Think: Lord of the Rings, Avatar.

Cinematic Real stakes Mild tension
🌑 💀 🗡️

Dark Fantasy

13+

Moody, atmospheric, genuinely challenging. Darker themes handled thoughtfully. Real consequences. Think: The Witcher (toned down), Dark Souls aesthetic.

Atmospheric Moody lighting Real stakes

Where Does Style Get Set?

A

During Onboarding

After adding players, before first adventure: "What vibe fits your family?"

B

Default Heroic, Change in Settings

Start with recommended style. Parents can adjust later if needed.

C

Per-Adventure Choice

Ask each time a new adventure starts. More flexible but more friction.

Updated Flow with Account

Welcome → Create Account (optional) → Add Players (names + ages) → Dice + Style → Characters → Play!

Players (kids) created once. Characters created per adventure. Style set once, changeable in settings.

Click the styles that make sense, and pick where style should be set. Then confirm in terminal.
