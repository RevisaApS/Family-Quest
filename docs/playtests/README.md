# Play notes

The engagement loop is blind without these. The game keeps everything in the
iPad's localStorage, there is no telemetry, and the loop cannot sit at the table.
So the only signal that reaches it is what Steven writes down after a session.

Keep it to five minutes. One file per session, named by date:
`docs/playtests/2026-09-14.md`. Bullet points beat prose. Danish or English.

```markdown
# 2026-09-14 · ~40 min · Lucas (Kriger) + Mason (Troldmand)

## Where they leaned in
- (a moment they talked about after, argued over, laughed at, asked to repeat)

## Where they drifted
- (phone-glance moments: waiting, long text, the other twin's turn, a modal)

## What they asked for / tried to do that the game couldn't
- ("kan jeg…", ideas typed as "Min egen idé", names they gave things)

## Did they ask to play again? When?
-

## Anything broken or confusing
-
```

The loop reads every note newer than its last run before it picks work. A single
line under "Where they drifted" outranks the whole backlog.
